Dashboard framework options (not Streamlit)
RECOMMENDED

Plotly Dash

Pure Python. Reactive callbacks re-run on any input change. You already have Plotly installed — Dash is just the server wrapper.

  • dcc.RangeSlider = time slider (D.2) in one line
  • Callbacks slice the in-memory DataFrame directly
  • DataTable widget for whitelist/blacklist (D.4)
  • One Docker service, pip install dash
MORE CONTROL

Flask + Plotly.js

Python Flask backend, charts rendered client-side via JSON endpoints. Full HTML/CSS control over layout.

  • Custom time slider in vanilla JS
  • REST endpoints for WL/BL edits
  • SSE or polling for live alert feed
  • Lightest Docker image of the three
FLEXIBLE

Panel (HoloViz)

Closest in feel to Streamlit but with explicit layout control. Works with Plotly, Matplotlib, and Bokeh out of the box.

  • pn.widgets.RangeSlider built in
  • param watchers handle reactive updates
  • Tabbed layouts easier than Streamlit
  • pip install panel — no extra deps
System architecture — data flow & state
Key design decisions baked into this architecture:   A processes the full PCAP in one pass and writes all_windows.parquet — the dashboard time slider never talks back to A, it just calls df[df.ts.between(t0, t1)] on the in-memory DataFrame loaded at startup.   D is read-only from the State Store except for whitelist.json / blacklist.json, which C polls before every mitigation decision.   Everything survives a Docker restart because all state lives in a mounted volume, not in-process memory.   Dashboard recommendation: Plotly Dash — dcc.RangeSlider handles D.2 in one line, dash_table.DataTable handles the WL/BL UI (D.4), and callbacks update all graphs on slider drag.
