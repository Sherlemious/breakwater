Architecture overview
Key design decisions: A processes the full PCAP in one pass and writes all_windows.parquet to disk. The dashboard time slider never talks back to A — it calls df[df.ts.between(t0, t1)] on the DataFrame loaded into memory at startup. D is read-only from the State Store except for whitelist.json / blacklist.json, which C polls before every mitigation decision. All state lives in a Docker-mounted ./data volume so nothing is lost on container restart.

Dashboard pick: Plotly Dash — dcc.RangeSlider covers D.2, dash_table.DataTable covers D.4, and reactive callbacks update all charts on every slider drag without any custom JS.
